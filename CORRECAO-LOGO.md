# Correção da logo

A imagem usada pelo projeto está em:

```text
assets/logo.png
```

O `config.js` deve conter:

```javascript
LOGO_URL: "assets/logo.png",
```

A mesma imagem aparece no cabeçalho e, com baixa opacidade, como marca-d'água no fundo. Depois de enviar os arquivos ao GitHub, atualize a página com `Ctrl + F5` ou limpe o cache do navegador.

No GitHub, confira se o nome está exatamente como `logo.png`. O GitHub diferencia maiúsculas e minúsculas: `Logo.png` e `logo.png` são arquivos diferentes.
